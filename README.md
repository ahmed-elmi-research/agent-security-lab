# Agent Security Lab — Ahmed Elmi

A public learning and research lab by **Ahmed Elmi**, part of [Ahmed Elmi Research](https://github.com/ahmed-elmi-research).

I am developing my expertise in the security of AI systems by conducting experiments and openly documenting my methods and findings. My first investigation concerns authorization when agent tasks resume. This is an individual research initiative, not an institute or an affiliation with any AI vendor.

## Research question
How can an AI agent remain within its current authorization when a task is interrupted and later resumed?

## Status
Initial research scaffold, started 24 November 2026. No experiments have been executed or validated in this repository yet. The earlier Hervat lab and its original files have not been imported. This is a learning and research project, not a production security product.

## Research method
Write a prediction before running a test. Record the exact commit, environment, command, inputs, observed outputs, and limitations. Include legitimate tasks as controls. Separate observations from interpretations. Publish negative results too. Never label a proposed experiment as completed.
