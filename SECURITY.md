# Security policy

This repository currently contains research plans and learning materials, with no production release or supported runtime.

Use GitHub's private vulnerability reporting feature under Security → Report a vulnerability for sensitive findings in this repository. Do not include exploitable details or secrets in a public issue. Findings affecting other projects should be reported privately to their maintainers first. No response-time guarantee is offered.

Experiments use local simulations and synthetic data. Test external systems only with explicit authorization. Remove credentials, personal information and third-party confidential material before sharing evidence.
