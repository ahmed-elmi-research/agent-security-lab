# Les 1 — Toestemming

Een AI-agent kan handelingen uitvoeren, zoals een bestand lezen of een bericht versturen. Toestemming bepaalt welke handelingen hij mag uitvoeren.

Situatie: je geeft een agent toestemming om een rapport te versturen. Hij wordt onderbroken voordat hij dat doet. Tijdens de pauze trek jij die toestemming in. Daarna hervat hij zijn werk.

Vraag aan Ahmed: mag de agent het rapport nu versturen, en waarom denk je dat?

Status: wacht op antwoord. Nog geen proef uitgevoerd.
