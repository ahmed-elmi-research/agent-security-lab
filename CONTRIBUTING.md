# Contributing

Everyone may read, fork and propose changes through issues and pull requests. Direct write access is restricted to maintainers.

For research contributions, supply a clear question, reproduction steps, expected and observed behavior, environment, synthetic inputs, limitations and relevant references. Distinguish new results from hypotheses. Disclose substantive AI assistance.

Keep learner exercises intact. Do not submit reference answers to pending exercises. Use a separate branch and a focused pull request. Maintainer review is required before acceptance. Be respectful and discuss evidence rather than people.
